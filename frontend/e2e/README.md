# E2E 테스트 (Playwright)

로컬 프론트(`npm run dev`, 5173)와 백엔드(8080)를 먼저 띄운 뒤 실행한다.

```bash
export E2E_USER_A_ID=... E2E_USER_A_PW=...   # 기본 사용자
export E2E_USER_B_ID=... E2E_USER_B_PW=...   # A와 같은 채팅방에 있는 사용자 (실시간 채팅)
export E2E_USER_C_ID=... E2E_USER_C_PW=...   # A/B 공통 채팅방의 모임 멤버가 아닌 사용자 (권한 차단 확인, 참여 신청)
# 이름이 기본값(트립메이트)과 다르면 E2E_USER_A_NAME=... 도 지정
npx playwright test
npx playwright show-report e2e-report        # 결과 리포트
```

계정 정보는 저장소에 커밋하지 않는다(`e2e/.env.e2e`는 gitignore 대상).

## 데이터를 만드는 시나리오

회원가입(E2E-01), 소모임 최종 생성(E2E-13b), 참여 신청(E2E-14), 실시간 채팅/읽음(E2E-16/17),
비멤버 채팅 차단(E2E-21)은
연결된 DB에 실제 데이터를 남긴다. 기본값에서는 스킵되고, 테스트용 DB에 연결했을 때만
`E2E_ALLOW_WRITES=1`을 붙여 실행한다. 이 시나리오가 만든 데이터에는 `[E2E]`, `e2e+...@tripmate.test` 표시가 붙는다.

## 참고

- E2E-09(AI 여행지 검색)은 프론트에 화면이 없어 `/tourList/tourAiSearch` API를 직접 호출해 검증한다.
  Gemini가 429/503/402(크레딧 소진)이면 `AI_UNAVAILABLE`로 실패한다.
- E2E-10은 번역 캐시가 없으면 첫 응답이 한국어일 수 있어, 새로고침하면서 최대 45초까지 기다린다.
- E2E-23~25는 관광지 이용정보 탭 검증이다. E2E-23은 경복궁(126508)의 TourAPI 국문/영문/일문 값을,
  E2E-24는 번역이 없을 때 한국어 원문 대체 표시를, E2E-25는 AI 조사로 보완된 항목의 출처 표시를
  응답 모킹으로 확인한다(운영 DB에 가짜 조사값을 넣지 않기 위해). E2E-24는 해당 관광지 번역이
  이미 저장돼 있으면 건너뛴다.

## 테스트 계정 정리

- E2E-01(회원가입)과 E2E-26(회원 탈퇴)은 테스트가 끝나면 만든 계정을 회원 탈퇴로 스스로 정리한다.
- 남아 있는 테스트 계정은 백엔드를 띄운 PC에서 `GET http://localhost:8080/e2e/accounts`(로컬 전용, 읽기 전용)로 확인한다.
  E2E-01 계정은 아이디가 `e2e+<13자리 숫자>@tripmate.test`, 이름이 `E2E<숫자 끝 6자리>`, 비밀번호가 `E2eTest!2345`이다.
- 셋업용 A/B/C 계정과 `[E2E] 셋업 모임`(A/B 공통 채팅방)은 채팅 시나리오(E2E-15/16/17/21)에 필요하므로 지우지 않는다.
- 탈퇴한 계정은 개인정보를 비운 채 상태(D)로 남는다(아이디 재사용 불가).
